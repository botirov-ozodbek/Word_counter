# 📊 Simple Word and Character Counter

A simple, lightweight Python script designed to count words and characters in any given text. Perfect for quick essay checks, writing metrics, and personal study tracking.

## ✨ Features
- **Word Count:** Accurately counts total words, filtering out empty spaces.
- **Character Count (With Spaces):** Calculates the total number of characters including spaces.
- **Character Count (Without Spaces):** Calculates the exact character count excluding all spaces.

## 🚀 How to Run

1. Make sure you have **Python 3.x** installed.
2. Clone or download this repository.
3. Open your terminal or code editor and run:
   ```bash
   python word_counter.py
